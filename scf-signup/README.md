# 金胡杨战队招新报名 - 云函数部署说明

## 1. 获取 QQ 邮箱 SMTP 授权码

1. 登录 QQ 邮箱 → 设置 → 账户
2. 找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务」，开启 SMTP 服务
3. 按提示用手机发送短信验证，生成 16 位授权码（已生成则无需重复操作）

## 2. 创建云函数

1. 打开 [腾讯云云函数控制台](https://console.cloud.tencent.com/scf)
2. 新建函数 → 选择「从头开始」：
   - 函数名称：`jinyang-signup`（随意）
   - 地域：与你的 EdgeOne/其他服务就近即可
   - 运行环境：**Python 3.6 或更高**
   - 执行超时：**30 秒**
3. 把本目录的 `index.py` 内容全部粘贴到函数代码中
4. 在「环境变量」中配置：
   - `QQ_MAIL` = 你的 QQ 邮箱地址
   - `QQ_AUTH_CODE` = 刚才的 16 位授权码
   - `TO_MAIL` = 收件邮箱（不填则默认发到 QQ_MAIL）
5. 保存并部署

## 3. 创建「函数 URL」触发器

> API 网关产品已于 2025 年停服，现在使用官方的「函数 URL」替代，适用于事件函数，配置更简单。

1. 函数详情 → 触发管理 → 创建触发器
2. 触发方式选 **函数 URL**
3. 鉴权方式选 **免鉴权**（报名表需要公开访问；若控制台无此选项则保持默认公网可访问）
4. 建议在默认版本（$LATEST）上开启
5. 创建后复制函数 URL（形如 `https://<app-id>-<url-id>.ap-guangzhou.tencentscf.com`）
6. **无需配置 CORS**：函数代码已内置跨域响应头并处理 OPTIONS 预检请求

函数 URL 的调用同样计入云函数免费额度。

## 4. 把网址填进网页

打开 `E:\user\Desktop\git\index.html`，搜索 `FORM_API_URL`，把占位地址替换成上面复制的访问路径。

## 5. 测试

刷新网页，填写报名信息提交：
- 收到邮件 = 成功
- 页面提示「提交失败」= 查看云函数日志（云函数控制台 → 日志查询）定位原因
